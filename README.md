# Python Tkinter Image Carousel 🖼️

A lightweight and responsive desktop image carousel application built using Python. The application utilizes the Tkinter library for the graphical user interface (GUI) and the Pillow library for high-quality image processing and resizing.

### Features
- **Smooth Image Navigation:** Allows users to easily cycle forward and backward through a collection of images using interactive buttons.
- **Dynamic Image Scaling:** Uses the Pillow library to handle image processing, ensuring images are correctly scaled to fit the application viewport.
- **Clean UI Layout:** Designed with a clean, centered interface focused on simplicity and usability.

### Built With
- **Language:** Python
- **GUI Framework:** Tkinter
- **Image Processing:** Pillow (PIL)

### How to Run Locally
1. Clone the repository to your machine:
   ```bash
   git clone https://github.com
   ```
2. Install the required image processing library:
   ```bash
   pip install Pillow
   ```
3. Run the application:
   ```bash
   python main.py
   ```
*(Note: Replace `main.py` with your actual Python file name if it is named differently, like `carousel.py`.)*
